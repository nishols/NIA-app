# NIA — Assistente Inteligente Multitarefa 🤖

A NIA é uma assistente de inteligência artificial criada para ajudar o utilizador em várias tarefas do dia a dia.

## 🚀 Funcionalidades

- 💬 Conversação com inteligência artificial
- 🎙️ Assistente por voz
- 🌍 Suporte a vários idiomas
- 👗 Consultora de estilo e moda
- 👚 Análise das roupas que o utilizador possui em casa
- 🏠 Integração futura com dispositivos e câmeras da casa
- 📚 Ajuda nos estudos e aprendizagem de idiomas
- 📅 Organização de tarefas e rotina
- 💡 Sugestões e assistência personalizada

## 💎 NIA Plus

A NIA terá um pacote Plus com funcionalidades avançadas.

## 🎁 Programa de indicação

O utilizador que convidar **15 pessoas elegíveis** poderá ganhar **2 semanas grátis do NIA Plus**.

## 🛠️ Tecnologias

O projeto poderá utilizar:

- Inteligência Artificial
- API da OpenAI
- Backend
- Aplicação Android
- Banco de dados
- Sistema de autenticação

## 🎯 Objetivo

Criar uma assistente inteligente, acessível e multifuncional que ajude as pessoas nas suas tarefas diárias através de texto e voz.
